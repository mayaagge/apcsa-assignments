1. How would you solve this problem with recursive backtracking? Would you duplicate the entire board each time you make the recursive call?

We would go through each row and place a queen one after the other and then go back to check for the other possibilities using recursive backtracking so we would not duplicate the entire board each time we make the recursive call.

2. How could you place the queens on the board making sure no queens will attach each other?

We could make sure no queens will attack each other by marking all the spots the queens are attacking with a number > 0 and marking the spots the queens are occupying with negative and then placing the queens only on spots that are safe which are 0.

3. How can you indicate if a position on the board is safe to add a queen?

We can indicate if a position on the board is safe to add a queen by letting the safe spots be 0 and the attacked or occupied spots with number or -1.
